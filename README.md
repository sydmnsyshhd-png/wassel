# WASSEL | وصّل

مشوارك علينا. وطلبك علينا كمان.

Landing page for **Wassel**, a local delivery service in New Salhia (الصالحية الجديدة), Egypt. Order anything from anywhere in the city, from a taameya sandwich to household shopping, and Wassel brings it to your door.

## Live site

https://sydmnsyshhd-png.github.io/wassel/

## Files

- `index.html` - page structure (Arabic, RTL)
- `style.css` - styling
- `script.js` - intro animation and page interactions, with optional Supabase placeholders for a backend (fill in `SUPABASE_URL` and `SUPABASE_ANON_KEY` to enable it)

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
